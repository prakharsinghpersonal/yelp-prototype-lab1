## 🚀 Getting Started

### Prerequisites

| Tool | Version | Check |
|---|---|---|
| Python | 3.9+ | `python3 --version` |
| Node.js | 18+ | `node --version` |
| MySQL | 8.0+ | `mysql --version` |
| npm | 9+ | `npm --version` |

### 1. Clone the Repository

```bash
git clone https://github.com/prakharsinghpersonal/yelp-prototype-lab1.git
cd yelp-prototype-lab1
```

### 2. Database Setup

```bash
# Connect to MySQL and create the database
mysql -u root -e "CREATE DATABASE IF NOT EXISTS yelp_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

> Tables are auto-created by SQLAlchemy ORM when the backend starts. Optionally run the seed script for sample data.

### 3. Backend Setup

```bash
cd backend

# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate        # macOS/Linux
# venv\Scripts\activate          # Windows

# Install dependencies
pip install -r requirements.txt

# Configure environment variables
cp .env.example .env
# Edit .env with your credentials (see Environment Variables below)

# Seed the database with sample data (optional but recommended)
python db/seed.py

# Start the server
uvicorn main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`

### 4. Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env
# Edit .env if needed (default API URL: http://localhost:8000)

# Start the dev server
npm run dev
```

The app will be available at `http://localhost:5173`

## 🤖 AI Assistant Chatbot

The AI chatbot provides personalized restaurant recommendations using:

- **Google Gemini** (via Langchain) for natural language understanding
- **Tavily Web Search** for real-time external context (hours, events, trending)
- **User Preferences** loaded from the database (cuisine, price, dietary, ambiance)
- **Multi-turn Conversations** with conversation history

### How It Works

1. User sends a message (e.g., *"I'm looking for a place for dinner tonight"*)
2. The system loads the user's saved preferences from MySQL
3. Langchain processes the query with a system prompt containing preferences + restaurant DB data
4. Tavily optionally enriches context with web search results
5. Gemini generates a personalized, conversational response with restaurant recommendations
6. Results are returned as structured JSON with clickable restaurant cards

### API Usage

```json
POST /ai-assistant/chat
{
  "message": "Something romantic for an anniversary",
  "conversation_history": []
}
```

## 🗄️ Database Schema

| Table | Key Columns |
|---|---|
| **users** | id, name, email (unique), password_hash, phone, about_me, city, state, country, gender, language, profile_pic_url, role, created_at |
| **restaurants** | id, name, cuisine_type, description, address, city, zip, phone, hours, price_tier ($–$$$$), amenities (JSON), owner_id FK, avg_rating, review_count, view_count, created_at |
| **reviews** | id, user_id FK, restaurant_id FK, rating (1–5), comment, created_at, updated_at |
| **photos** | id, restaurant_id FK, review_id FK (nullable), url, created_at |
| **favorites** | id, user_id FK, restaurant_id FK, created_at |
| **user_preferences** | id, user_id FK, cuisines (JSON), price_range, preferred_locations (JSON), search_radius, dietary_needs (JSON), ambiance (JSON), sort_preference |
